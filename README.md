# Class Tools

학급 운영 도구 모음입니다. 브라우저에서 `index.html`을 열면 사용할 수 있습니다.

드래그(SortableJS), 엑셀 업로드(SheetJS), 글꼴(Pretendard)은 `vendor/`에 포함되어 있어 인터넷이 끊겨도 동작합니다. 라이선스는 `vendor/NOTICE.md`를 참고하세요.

## 데이터

학급 데이터는 이 브라우저(localStorage)에만 저장됩니다. 관리실 → **백업 다운로드**로 주기적으로 파일을 받아 두세요.
14일 넘게 백업하지 않으면 홈 화면에 알림이 뜨고, 백업 복원·전체 초기화 직전 데이터는 **되돌리기**로 한 번 되살릴 수 있습니다.

## 파일 구조

| 파일 | 역할 |
|---|---|
| `script.js` | 화면 전환·관리실·자리배치·모둠·발표순서·이벤트 연결 (공통 `app` 객체를 만들어 아래 모듈에 넘김) |
| `seat-rules-panel.js` | 자리배치 규칙 설정 창, 위반 알림, 이번 자리 확정 |
| `duties-panel.js` / `random-panel.js` / `timer-panel.js` | 당번관리 / 랜덤게임·룰렛 / 타이머 화면 |
| `print-output.js` | 인쇄, 좌석표 미리보기, 크게보기 |
| `storage.js` | 저장·백업·복원·되돌리기 |
| `*-manager.js`, `*-engine.js` | 화면과 무관한 계산 (자리 배치 규칙 엔진 등) |

`index.html`은 로컬 파일을 `?v=날짜`를 붙여 불러옵니다. JS·CSS를 고쳐 배포할 때는 `python tools/bump_version.py`로 이 값을 올려야 사용자 브라우저가 예전 파일을 캐시에서 쓰지 않습니다.

## 문서변환 (한글 → PDF)

허브의 **문서변환**에서 `.hwp` / `.hwpx`를 PDF로 바꿉니다.

브라우저에서 바로 변환됩니다. 파일은 외부 서버로 올라가지 않습니다.
내장 한글 폰트(Noto KR Regular/Bold)와, 가능하면 PC에 있는 함초롬·맑은고딕 등을 함께 사용합니다.

(선택) 한컴 한글이 설치된 PC에서 `converter/실행.bat`을 실행하면, 연결된 동안 해당 엔진으로 더 정밀하게 변환할 수 있습니다.
